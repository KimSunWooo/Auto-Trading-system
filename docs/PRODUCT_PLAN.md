# 미리매수 PRODUCT_PLAN

일반 투자자가 전략을 고르고, 과거 성과를 본 뒤, 한도를 확인한 다음 자동매매를 켜는 B2C 알고리즘 트레이딩 플랫폼.

기존 백엔드 경계는 유지한다. `IBroker` → `OrderManager` → 전략 버킷, `MockBroker` / `KisBroker` 어댑터, `QuantEngine` 틱 루프를 우회하거나 대체하지 않는다.

## 핵심 가치

- 자산·수익률이 한눈에 보이도록 한다.
- 전략을 켜기 전에 백테스트 숫자를 보여 신뢰를 만든다.
- 일일 손실·종목 비중·손절·긴급 정지로 사고를 막는다.

## 아키텍처 (유지)

```
전략 / 조건 / 적립 / 수동
        │
        ▼
     IBroker
   ┌────┴────┐
MockBroker  KisBroker
        │
        ▼
  OrderManager  →  RiskManager (상품 한도) + HARD_LIMITS (최후 캡)
        │
        ▼
  QuantEngine 틱 (시세 → 손절 → 일일손실 → 조건/적립/전략)
```

증권사 확장은 Broker 어댑터만 추가한다. 계좌·전략·주문·엔진 분리를 깨지 않는다.

## 전략 이름 (사용자 대면)

| 내부 id | 화면 이름 | 설명 |
| --- | --- | --- |
| `Level1_Stable` | 안정형 | KODEX 200 정액 적립. 낮은 변동성. |
| `Level5_Swing` | 중립형 | 5일/20일 이동평균 스윙. |
| `Level10_Aggressive` | 공격형 | 변동성 돌파 단기 추격. |

내부 클래스명과 버킷 키는 바꾸지 않는다.

## 상품 리스크 (HARD_LIMITS와 별개)

하드 캡(주문 200만, 일 매수 500만, 일 30건, 종목 50%)은 그대로 최후 방어선이다. 상품 리스크는 그보다 먼저 막는다.

| 항목 | 기본값 | 동작 |
| --- | --- | --- |
| 일일 최대 손실 | -3% | 당일 평가금액이 시가 대비 -3%면 서킷 오픈, 당일 자동매매 정지 |
| 종목 비중 | 20% | 평가금액 기준 한 종목 20% 초과 매수 거부 |
| 손절 | -5% | 평단 대비 -5%면 해당 버킷을 현재가 -3% 지정가 밴드로 분할 매도 (시장가 아님) |
| 긴급 정지 | Kill switch | 신규 매매 중지 → KIS 미체결 즉시 취소 → 지정가 밴드 분할 매도 → inquire-balance로 로컬 장부 덮어쓰기. 정규장(09:00~15:20) 외 신규 주문 차단. 247540 등 고변동 종목은 시장가 금지 |

## 백테스트

실시간 시세 대신 일봉 배열을 `BacktestRunner`에 넣어 `QuantEngine` + `MockBroker` + 같은 `IStrategy`를 재생한다. 결과: 총 수익률, MDD, 승률, 거래 횟수, 평균 수익/손실, 자산곡선, 체결 리스트.

## 온보딩 (5단계)

1. 증권사: 로컬 모의 / 한국투자증권(서버 `.env.local` 앱키)
2. 투자금: 자동매매에 맡길 예산
3. 전략: 안정형 / 중립형 / 공격형
4. 백테스트 미리보기
5. 리스크 한도 확인 후 자동매매 시작

KIS 앱키는 브라우저에 받지 않는다. 키는 기존처럼 서버 환경변수다.

## 개발 마일스톤 (4단계)

1. **대시보드** — 총자산·평가손익·당일 매매·승률 위젯, 세 전략 카드, 자동매매 토글.
2. **리스크** — `RiskManager`를 주문 게이트와 틱에 연결. 일일손실·비중·손절·긴급정지.
3. **백테스트** — `BacktestRunner`가 과거 일봉으로 전략을 재생하고 지표를 반환.
4. **온보딩** — 5스텝 위저드가 배분·백테스트·시작 토글을 한 흐름으로 묶는다.

Phase 2 (이 슬라이스 밖): 텔레그램/카카오 알림, 노코드 전략 빌더.
